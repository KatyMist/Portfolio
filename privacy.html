Privacy Policy and Cookie Usage

Last updated: July 1, 2026

1. General Provisions

This Privacy Policy and Cookie Usage Policy has been drawn up in accordance with Federal Law No. 152-FZ "On Personal Data" dated July 27, 2006, and sets out how cookies are used and how anonymized data is processed, along with the protective measures taken by Ekaterina Anatolyevna Tumanova (hereinafter referred to as the "Operator").

The Operator's goal is to uphold human and civil rights and freedoms when processing personal data.

This Policy applies to the entire website: https://katymist.github.io/Portfolio/

2. Key Terms Used in this Policy

This Policy uses the following terms:

User — any visitor to the website https://katymist.github.io/Portfolio/.

Cookies — small pieces of data stored on the user's device and used to ensure the website functions correctly and to analyze traffic.

Anonymized data — information that does not allow the user to be identified, directly or indirectly, including technical data about the device, browser, and on-site activity.

Web analytics — analysis of website traffic using the third-party service Yandex.Metrica.

3. Basic Rights and Obligations of the Operator

3.1. The Operator has the right to:

  • independently determine the set of measures required to ensure the security and protection of anonymized data processed via web analytics services;
  • use users' anonymized data for statistical analysis and to improve the website.

3.2. The Operator is obligated to:

  • ensure this Policy is published and accessible on the website;
  • take the necessary measures to protect anonymized data collected via web analytics services;
  • comply with the requirements of Russian Federation law regarding the processing of anonymized data and the use of cookies;
  • restrict access to data processed by third-party services (including Yandex.Metrica);
  • stop processing data in cases provided for by Russian Federation law.

4. Basic Rights and Obligations of Data Subjects

4.1. The User has the right to:

  • receive information about the processing of anonymized data used on the website;
  • restrict the use of cookies in their browser settings;
  • opt out of anonymized data processing by disabling cookies or using the relevant browser settings;
  • contact the Operator regarding data processing matters.

4.2. The Operator does not process personal data that would allow the user to be directly identified and does not store user profiles.

5. Principles of Processing Anonymized Data

5.1. The processing of anonymized data is carried out on a lawful and fair basis.

5.2. The processing of anonymized data is limited to achieving specific, lawful purposes — analyzing traffic and improving the website.

5.3. Combining data obtained for different processing purposes is not permitted if it contradicts the stated purposes.

5.4. Only the anonymized data necessary to achieve the processing purposes is processed.

5.5. The content and scope of the data processed correspond to the processing purposes. Excessive data processing is not carried out.

5.6. The Operator takes measures to ensure the accuracy and relevance of anonymized data within the web analytics services used.

5.7. Anonymized data is stored in a form that allows the user to be identified for no longer than the processing purposes require, or in accordance with the policies of third-party services (including Yandex.Metrica). For more details: Yandex.Metrica Terms of Use

6. Purposes of Processing Anonymized Data

The purpose of data processing is to analyze website traffic and improve the site using the Yandex.Metrica web analytics service.

The website does not independently collect users' personal data, such as first name, last name, email address, or other data that would directly identify the user.

When visiting the website, anonymized data may be processed automatically, including:

  • cookie files;
  • technical data about the user's device and browser;
  • information about the user's actions on the website (page views, navigation).

This data does not make it possible to establish the user's identity.

7. Data Processing Conditions

7.1. Data is processed based on the user's consent, expressed through the use of the website and acceptance of cookie settings.

7.2. Data processing is necessary solely for web analytics purposes and to improve the website using the Yandex.Metrica service.

7.3. The website does not process personal data for the purposes of concluding contracts, providing services, or fulfilling government or other obligations that require user identification.

7.4. Anonymized data may only be processed within the operation of the third-party web analytics service and in accordance with its privacy policy.

7.5. The processing of data that the user has made publicly available or provided voluntarily (should such a situation arise) is carried out within the limits of the applicable law of the Russian Federation.

8. Procedure for Collecting, Storing, Transferring, and Otherwise Processing Data

8.1. The security of data processed on the website is ensured through technical and organizational measures aimed at protecting information within the use of third-party web analytics services.

8.2. The website does not independently store or process users' personal data.

8.3. Data processing takes place solely within the use of the Yandex.Metrica service and is limited to collecting anonymized statistical information about website visits.

8.4. Data is transferred to third parties only within the operation of the third-party web analytics service and in accordance with its privacy policy.

8.5. The user can restrict or disable data processing by changing their browser settings or declining the use of cookies.

8.6. The data retention and processing period is determined by the policies of third-party services (including Yandex.Metrica) and the user's browser settings.

9. Actions Performed on Processed Data

The Operator does not independently process users' personal data in the form of storage, systematization, clarification, or destruction.

Data processing on the website is limited to the use of anonymized information obtained through the Yandex.Metrica service.

The following actions may be performed on anonymized data as part of the website's operation:

  • collecting and analyzing statistical information about website visits;
  • using cookies and technical browser data;
  • transferring anonymized information to web analytics services for processing in accordance with their privacy policies.

Automated data processing is carried out exclusively by means of third-party web analytics services and does not involve the creation of personal data databases on the Operator's side.

10. Cross-Border Transfer of Personal Data

The Operator does not independently carry out cross-border transfers of users' personal data.

The processing of anonymized data may be carried out using the third-party service Yandex.Metrica, in accordance with its privacy policy and data processing infrastructure.

11. Confidentiality of Data

The Operator ensures the confidentiality of processed data within the use of web analytics services.

The website does not independently collect or store users' personal data.

Data processing is limited to the use of anonymized information obtained through the Yandex.Metrica service, in accordance with its privacy policy.

Access to data is carried out exclusively within the operation of third-party web analytics services.

Data is not transferred to third parties, except in cases provided for by the policies of the third-party services used and by the law of the Russian Federation.
